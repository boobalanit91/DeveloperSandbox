Document Q&A using RAG in .NET Core

A beginner-friendly sample demonstrating how to upload a document and ask questions about its content using Retrieval-Augmented Generation (RAG) with .NET and C#.

.NET / C# RAG Document Q&A Learning project

What does this application do?

The application provides a simple way to interact with information inside a document. First, a user uploads a document through the document-upload API. The application processes the document so its content can be retrieved later. The user can then submit a question, and the application uses relevant document content to help generate an answer.

Project scope: This is a basic learning implementation created to understand the RAG workflow and how AI capabilities can be integrated into a .NET application. It is not intended to represent a production-ready document intelligence platform.

How it works

1

Upload a document

Send a document to the upload endpoint. The application receives it for processing.

2

Prepare the content

The document content is extracted and prepared for retrieval. In a typical RAG flow, this includes splitting the text into smaller chunks and creating embeddings.

3

Ask a question

Send a question related to the uploaded document to the question endpoint.

4

Retrieve and answer

The application retrieves relevant content and uses it as context for the AI model to generate a response.

Understanding the RAG flow

RAG combines information retrieval with text generation. Instead of relying only on the language model's existing knowledge, the application first searches the uploaded document for content relevant to the user's question. That retrieved content is then provided as context when generating the answer.

API usage

The sample exposes two main operations: one to upload a document and another to ask a question about the document. Replace the example paths below with the actual routes configured in your application.

1. Upload a document

Method: POST
Example route: /api/documents/upload

Send the document using the request format expected by your API (commonly multipart/form-data for a file upload). 

curl -X POST "https://localhost:5001/api/documents/upload" \
  -F "file=@sample-document.pdf"

2. Ask a question

Method: POST
Example route: /api/documents/ask

Submit a question related to the document. The property names below are illustrative; use the request model defined by your API. 

curl -X POST "https://localhost:5001/api/documents/ask" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "What are the main points in this document?"
  }'
Note: The endpoint paths, port, form field name, and JSON properties in these examples are placeholders. Update them to match the actual controller routes and request models in your project.

Example use case

  1. Upload a document containing project or business information.
  2. Ask a question such as: “What are the key points discussed in this document?”
  3. The application searches for relevant content from the uploaded document.
  4. The AI model uses that content to generate a response.
